# Smart Travel Planner 🌍

Smart Travel Planner is a simple travel planning website designed to help users explore destinations, estimate travel costs, and discover hotels and famous attractions in Bangladesh.

The project includes destination cards, hotel recommendations, famous tourist attractions, weather checking, trip budgeting, and map integration in a clean and user-friendly interface.

---

## Features

1. Beautiful travel-themed homepage  
2. Popular destination showcase  
3. Famous attractions with images  
4. Hotel recommendations with room images  
5. Trip cost calculator  
6. Destination search system  
7. Real-time weather information  
8. Google Map integration  
9. Smooth scrolling navigation  
10. Image slider/gallery  
11. Dark mode toggle  
12. Responsive and modern UI  

---

## Technologies Used

1. HTML5  
2. CSS3  
3. JavaScript  
4. OpenWeather API
